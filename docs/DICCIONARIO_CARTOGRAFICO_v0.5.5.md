# Diccionario cartográfico v0.5.5

## Capa cantonal

Archivo: `assets/data/cantones_zonal5_wgs84_v0.5.5.geojson`

- Tipo: FeatureCollection
- Entidades: 51 cantones
- CRS original: EPSG:3857 / Web Mercator
- CRS de salida: WGS84 / EPSG:4326
- Uso: selector territorial cantonal del módulo Riesgo zonal

## Campos principales

- `provincia`: nombre de provincia.
- `provincia_id`: identificador normalizado.
- `canton`: nombre de cantón.
- `canton_id`: código cantonal DPA.
- `codigo_dpa`: código cantonal DPA.
- `zona`: CZ5.
- `area_km2`: área referencial de la geometría fuente.
- `poblacion_referencial`: población referencial incluida en el archivo fuente.
- `semaforo`: pendiente hasta integrar datos de planes firmados.
- `estado_datos`: estado de extracción documental.

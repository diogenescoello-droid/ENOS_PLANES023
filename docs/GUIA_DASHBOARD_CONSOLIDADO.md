# Guía rápida de implementación

1. Entrar al repositorio `ENOS_PLANES023` en GitHub.
2. Abrir `index.html`.
3. Presionar el lápiz de edición.
4. Seleccionar todo el contenido actual.
5. Reemplazarlo por el contenido del nuevo `index.html`.
6. En `Commit changes`, escribir: `Actualiza dashboard consolidado ENOS CZ5`.
7. Confirmar el commit en la rama `main`.
8. Esperar 1 a 2 minutos y abrir GitHub Pages.
9. Presionar `Ctrl + F5`.
10. Entrar a la pestaña `5. Dashboard` y presionar `Actualizar consolidado`.

La pestaña debe mostrar los datos consolidados de la API documental: total GAD, planes gestionados, validados, faltantes, en revisión y devueltos.

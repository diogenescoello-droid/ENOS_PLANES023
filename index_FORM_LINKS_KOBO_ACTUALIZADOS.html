Flujo operativo ENOS Zona 5

Use los módulos en orden: llenar datos, actualizar base y generar prompt, usar GPT y descargar, y respaldar/cerrar.

Perfil: GAD cantonal

1. Llenar datos

Complete los formularios Kobo actualizados. Esta versión mantiene la página estable y solo actualiza el bloque de formularios.

Edite los enlaces en la sección FORM_LINKS del archivo index.html si los formularios Kobo cambian.

Control de captura

  • F01 identifica sitios críticos.
  • F02 incorpora infraestructura expuesta.
  • F03 registra aporte cartográfico.
  • F04 documenta acciones y responsables.
  • F05 levanta alojamientos y puntos seguros.
  • F06 registra capacidades.
  • F07 consolida seguimiento mensual.

Actualizar base y generar prompt GPT

Use el mismo código de caso en todos los formularios. Cuando tenga datos cargados, genere un prompt técnico para el asistente ENOS Zona 5.

Prompt GPT generado

Control técnico

  • F01 identifica el caso o sitio base.
  • F02-F07 complementan infraestructura, cartografía, acciones, capacidades y seguimiento.
  • Si faltan datos, GPT debe reportarlos como pendientes.
  • Esta versión no usa catálogo dinámico ni búsqueda guiada.

3. GPT y descarga

Copie el prompt generado, úselo en ChatGPT y descargue el resultado técnico para revisión institucional.

Uso recomendado

  • Revise que el código del caso sea el correcto.
  • No mezcle registros de distintos GAD o instituciones.
  • Use el resultado GPT como borrador técnico sujeto a revisión.
  • Adjunte evidencias y medios de verificación.

4. Entrega y respaldo

Cargue respaldos, organice evidencias y conserve trazabilidad del proceso ENOS.

ProductoPlan, informe, matriz, ficha o resumen técnico.
Medio de verificaciónCarpeta Drive, PDF firmado, anexos, mapas, fotografías, actas o Quipux.
ResponsableActor que reporta y equipo técnico que valida.

Cierre operativo

  • Verificar que el plan tenga evidencias.
  • Confirmar que los datos críticos estén completos.
  • Guardar respaldo antes de generar versiones finales.
  • Registrar observaciones pendientes.

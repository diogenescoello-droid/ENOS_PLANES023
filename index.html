ENOS_PLANES023 · Ecosistema Digital CZ5 ENOS Guayas

Plataforma de apoyo para carga de formularios, actualización de base, búsqueda guiada de casos, generación de prompt GPT y descarga de productos técnicos asociados al Plan ENOS Zona 5.

Seleccione perfil de trabajo

La plataforma conserva la arquitectura modular. El ajuste aplicado está solo en el bloque de búsqueda y generación de prompt GPT.

01

Técnico territorial

Registra información, busca casos y genera prompts técnicos sin copiar códigos largos.

Uso recomendado para GAD, CZ5, instituciones sectoriales y equipos de campo.
02

Validador técnico

Revisa coherencia documental, cartográfica y operativa de los registros ENOS.

Permite filtrar por nivel, territorio, actor, formulario y caso visible.
03

Coordinación CZ5

Consulta casos, genera prompts consolidados y orienta seguimiento institucional.

Integra registros cantonales, provinciales y zonales.
04

Gestión documental

Organiza evidencias, carpetas Drive, folios y productos para descarga.

Compatible con búsqueda por folio, código existente o etiqueta visible.

Flujo operativo ENOS Zona 5

Use los módulos en orden: llenar datos, actualizar base y generar prompt, luego usar GPT y descargar el producto técnico.

Perfil: Técnico territorial

1. Llenar datos

Complete los formularios Kobo según el tipo de información: sitios críticos, infraestructura, cartografía, acciones, alojamientos, capacidades y seguimiento mensual.

F01 Sitios críticos F02 Infraestructura F03 Cartografía F04 Acciones F05 Alojamientos F06 Capacidades F07 Seguimiento

Control de captura

  • F01 crea sitios críticos.
  • F02 vincula infraestructura expuesta.
  • F03 agrega cartografía institucional.
  • F04 registra acciones y responsables.
  • F05, F06 y F07 completan operación, capacidades y seguimiento.

Actualizar base y generar prompt GPT

Sincronice Kobo, seleccione el caso mediante búsqueda guiada o código existente, y genere el prompt técnico para el asistente ENOS Zona 5.

Buscar caso para prompt GPT

Catálogo pendiente de conexión. Configure config.js con la URL del Web App de Apps Script. No se mostrarán opciones de prueba.

Control técnico

  • No se pide al técnico copiar códigos largos.
  • La búsqueda guiada usa nivel, territorio/actor y caso visible.
  • La búsqueda por código conserva compatibilidad con códigos ya creados.
  • Si no hay API conectada, no se muestran opciones falsas.
  • La fuente real debe ser la hoja CATALOGO_PROMPTS_GPT.

3. GPT y descarga

Pegue el prompt generado en el asistente GPT correspondiente y use la salida para informe, ficha, resumen técnico o paquete documental.

Uso recomendado

  • Genere el prompt desde la base.
  • Revise el caso visible antes de copiar.
  • Use el código oculto solo para trazabilidad interna.
  • No publique datos sensibles sin validación.
